# نِنا (Nena)

پلتفرم درخواست خودرو به سبک Uber برای ایران — کاملاً فارسی و راست‌به‌چپ، به‌صورت وب‌اپ (PWA) قابل نصب روی گوشی.

شامل سه اپ:

| اپ | آدرس | کاربر |
|---|---|---|
| **مسافر** | `/rider/` | درخواست سفر، پیگیری زنده، پرداخت، امتیازدهی |
| **راننده** | `/driver/` | ثبت‌نام و مدارک، آنلاین/آفلاین، دریافت و انجام سفر، درآمد و تسویه |
| **مدیریت** | `/admin/` | داشبورد زنده، تأیید رانندگان، تعرفه‌ها، تخفیف‌ها، ایمنی، تسویه |

## اجرا

```bash
npm install
npm start                 # http://localhost:3000
npm run simulate          # (ترمینال دوم) رانندگان شبیه‌سازی‌شده که سفرها را می‌پذیرند و انجام می‌دهند
npm test
```

نیاز: Node.js نسخه ۲۲.۱۳ یا بالاتر (پایگاه داده SQLite داخلی Node استفاده می‌شود؛ نصب پایگاه داده جداگانه لازم نیست).

در محیط توسعه، کد پیامکی ورود روی صفحه نمایش داده و در کنسول سرور چاپ می‌شود. شماره `09120000000` به‌صورت پیش‌فرض مدیر است.

### نمایش سریع
1. `npm start` و در ترمینال دیگر `npm run simulate`
2. `/rider/` را باز کنید، با هر شماره‌ای وارد شوید، مقصد را روی نقشه انتخاب و سفر درخواست کنید.
3. یک راننده شبیه‌سازی‌شده می‌پذیرد، روی نقشه به سمت شما حرکت می‌کند و سفر را انجام می‌دهد.
4. `/admin/` را با `09120000000` باز کنید تا سفرها و رانندگان را زنده ببینید.

**راننده:** ثبت‌نام سه‌مرحله‌ای با اعتبارسنجی کد ملی، پلاک ایرانی (خودرو و موتور) و شبا • بارگذاری مدارک • تم تیره • آنلاین/آفلاین • درخواست با شمارش معکوس و صدا • مسیریابی با نشان/بلد/Google/Waze • رسیدم، زمان‌سنج انتظار و هزینه توقف • شروع با کد سفر • «مسافر نیامد» با دریافت هزینه لغو • خلاصه پایان سفر و مبلغ نقدی • نقشه تقاضا • درآمد روزانه/هفتگی/ماهانه • کیف پول، بدهی کمیسیون، درخواست تسویه • نرخ پذیرش و امتیاز

**مدیریت:** آمار ۲۴ ساعته و نمودار ۱۴ روزه • نقشه زنده رانندگان و سفرها • بررسی مدارک و تأیید/رد/تعلیق رانندگان • مدیریت کاربران، مسدودسازی و اصلاح موجودی • جزئیات سفر و گفتگو، لغو توسط پشتیبانی • ویرایش تعرفه و کمیسیون هر سرویس • تنظیمات (هزینه لغو، زمان انتظار، شعاع جستجو، سقف Surge، کد سفر و…) • کدهای تخفیف • هشدارهای اضطراری لحظه‌ای • تأیید واریز تسویه‌ها

## معماری

```
server/
  index.js            Express + Socket.IO
  db.js               طرح پایگاه داده SQLite و داده‌های اولیه (تعرفه‌ها، تنظیمات)
  auth.js             JWT و کنترل دسترسی
  routes/             auth, rider, driver, admin, common (نقشه، گفتگو، SOS، ردیابی، درگاه)
  services/
    rides.js          چرخه عمر سفر، لغو، تسویه کرایه، امتیاز، انعام
    matching.js       تخصیص نزدیک‌ترین راننده، یکی‌یکی با مهلت پاسخ؛ رزروها
    pricing.js        کرایه، Surge، کد تخفیف
    routing.js        مسیر: تخمینی / OSRM / نشان
    payment.js        درگاه آزمایشی / زرین‌پال
    sms.js            آزمایشی / کاوه‌نگار
public/               اپ‌های مسافر، راننده و مدیریت (JavaScript خالص، بدون مرحله build)
scripts/simulate-drivers.js
test/                 تست‌های سرتاسری جریان سفر
```

**حسابداری کیف پول راننده:** موجودی راننده نشان می‌دهد نِنا چقدر به او بدهکار است (مثبت) یا او به نِنا (منفی). پس از هر سفر به اندازهٔ «کرایه − کمیسیون − نقد دریافتی» تغییر می‌کند؛ پس در سفر نقدی، کمیسیون بدهی می‌شود و در سفر کیف پولی، درآمد واریز می‌شود. تخفیف‌ها را نِنا می‌پردازد.

## راه‌اندازی در محیط واقعی (ایران)

فایل `.env.example` را ببینید. برای سرویس واقعی:

- `NODE_ENV=production` و `JWT_SECRET` تصادفی (در این حالت کد پیامک به کاربر نشان داده نمی‌شود)
- **پیامک:** `SMS_PROVIDER=kavenegar` با کلید و قالب Verify در کاوه‌نگار (`token` = کد)
- **پرداخت:** `PAYMENT_PROVIDER=zarinpal` با مرچنت زرین‌پال؛ `PUBLIC_URL` باید آدرس عمومی HTTPS باشد
- **نقشه:** برای جستجو و مسیریابی دقیق‌تر در ایران `GEOCODER=neshan` و `ROUTING_PROVIDER=neshan` با کلید API نشان. کاشی‌های نقشه از `TILE_URL` خوانده می‌شود.
- HTTPS الزامی است (موقعیت مکانی مرورگر و نصب PWA فقط روی HTTPS کار می‌کنند)
- اجرا با Docker: `docker build -t nena . && docker run -p 3000:3000 -v nena-data:/app/data --env-file .env nena`

### استقرار رایگان روی Render
[![Deploy to Render](https://render.com/images/deploy-to-render-button.svg)](https://render.com/deploy?repo=https://github.com/massihs/Nena)

فایل `render.yaml` سرویس را با پلن رایگان می‌سازد (`JWT_SECRET` خودکار، `EXPOSE_OTP=1` برای ورود بدون پیامک). هنگام ساخت، شماره مدیر را در `ADMIN_PHONES` وارد کنید.
در پلن رایگان سرویس پس از ۱۵ دقیقه بی‌استفاده به خواب می‌رود و دیسک ماندگار ندارد؛ داده‌ها با هر راه‌اندازی مجدد پاک می‌شوند (مناسب نسخه نمایشی).

### استقرار روی Railway
پروژه شامل `railway.json` است (ساخت با Dockerfile، بررسی سلامت روی `/api/health`، یک نمونه).
1. در Railway: **New Project → Deploy from GitHub repo** و انتخاب این مخزن/شاخه
2. **Volume** با مسیر `/data` به سرویس اضافه کنید (پایگاه داده و مدارک رانندگان)
3. متغیرها: `JWT_SECRET` (رشته تصادفی بلند)، `DB_PATH=/data/nena.db`، `UPLOAD_DIR=/data/uploads`، `ADMIN_PHONES=09...`
   و برای نسخه نمایشی بدون سرویس پیامک: `EXPOSE_OTP=1` (کد ورود روی صفحه نمایش داده می‌شود)
4. **Settings → Networking → Generate Domain**. آدرس عمومی به‌صورت خودکار از `RAILWAY_PUBLIC_DOMAIN` خوانده می‌شود.

### محدودیت‌های فعلی
- تماس مستقیم با شماره واقعی انجام می‌شود (ماسک کردن شماره نیاز به سرویس تلفنی دارد)
- مسیر راننده تا مبدأ و زمان رسیدن تخمینی است؛ کرایه پیش از سفر قطعی است (به‌علاوه هزینه توقف)
- تخصیص و تایمرها در حافظهٔ یک سرور است؛ برای چند سرور باید Redis و آداپتر Socket.IO اضافه شود
- تأیید هویت رانندگان دستی و توسط مدیر است؛ استعلام خودکار (ثبت احوال، پلیس راهور) متصل نشده است
- اعلان پوش زمانی که اپ بسته است پیاده نشده؛ اعلان مرورگر فقط هنگام باز بودن صفحه کار می‌کند

## English summary

Nena is an Uber-style ride-hailing web platform for Iran, fully in Persian (RTL, Jalali dates, toman, Persian digits). It ships a rider app, a driver app and an admin panel, all served by one Node.js server (Express, Socket.IO, built-in `node:sqlite`, no build step). Dispatch offers each request to the nearest idle driver with a timeout, then moves on. Pricing supports base/distance/time fares, minimum fares, surge, waiting fees, promo codes and per-service commission. Integrations: Kavenegar (SMS OTP), ZarinPal (wallet top-up), Neshan / OSRM / Nominatim (maps), each with a built-in mock for development. Run `npm start`, `npm run simulate`, `npm test`.
